# KATHEB Type 01 - walkable apartment tour

Static three.js viewer of the KATHEB Type 01 apartment (14 rooms + lift lobby) with Cycles-baked lighting and a Riyadh window view.
Three builds of the same model: `assets/katheb_v3_apartment_mobile.glb` (phones), `_medium.glb` (laptops / tablets) and
`katheb_v3_apartment.glb` (desktop PCs). The viewer picks one automatically; force it with `?q=mobile|medium|full`.

Credits: window view "Riyadh aerial helicam 2013" by Ville Hyvonen, CC BY-SA 2.0 (Wikimedia Commons); textures and scanned props
from Poly Haven and ambientCG (CC0); artworks from The Metropolitan Museum of Art Open Access (CC0); three.js (MIT).
